# Ejercicios JDBC

Reimplementación de la entrega `Sambade_Saa_Rodrigo_EjerciciosJDBC.rar`, que contenía los ejercicios 1, 2, 3, 4, 6, 7, 8 y 9.

En lugar de repetir conexiones y SQL vulnerable en ocho clases independientes, esta versión concentra la infraestructura común y expone ejemplos de: DDL, CRUD parametrizado, consultas, agregación, metadatos, lotes y procedimientos transaccionales.
